# Zoominfo Gtm-ai

## How do I install these formulae?

`brew install zoominfo/gtm-ai/<formula>`

Or `brew tap zoominfo/gtm-ai` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "zoominfo/gtm-ai"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
